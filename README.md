# 梅花易数解读系统

> 八卦取象、体用生克、卦象推演 — 易经占卜的深度解读框架。

## 关于

此项目包含梅花易数的完整解读方法论：起卦、体用分析、五行生克、八卦取象、季节旺衰、应期断法。

配合 [SpiritTool](https://github.com/Kico-Tachagemofet/Project-Hermes) 的易经起卦功能使用。

## 依赖

Python 3.10+，仅使用标准库。

## 快速开始

```bash
# 易经起卦
python3 scripts/yijing_draw.py
```

输出：本卦、变爻、之卦。

## 解读框架

1. **定体用** — 变爻在下卦则下为用上为体，反之上为用下为体
2. **五行生克** — 用生体大吉，体用比和吉，体克用中吉，体生用中凶，用克体凶
3. **取象推演** — 上下卦的原始物象在同一画面中互动
4. **之卦趋势** — 新的体用关系揭示未来力量格局
5. **变爻爻辞** — 最直接的信息指引
6. **季节旺衰** — 校准力量对比

文档包含八卦取象表（乾兑离震巽坎艮坤）、六十四卦速查、五行生克、季节旺衰、应期断法、驿马桃花等完整内容。
